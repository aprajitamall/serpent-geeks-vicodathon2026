# ABTalks Vibe Coding Prompts

## Project

ABTalks – India's 60-Day Coding Challenge

## Development Approach

This project was developed using AI-assisted vibe coding.
ChatGPT was used for planning, UI development, debugging,
component creation, styling, and feature improvements.

## Prompts Used

### 1. Project Structure

Create a React Vite project for an ABTalks 60-day coding
challenge platform with a landing page, student dashboard,
and daily challenge page.

### 2. Landing Page

Create a modern responsive landing page for ABTalks with
a hero section, statistics, features, how-it-works section,
student journey, testimonials, and CTA.

### 3. Dashboard

Create a student dashboard containing coding streak,
progress, today's task, achievements, and an AI Study Coach.

### 4. Challenge System

Create a 60-day challenge grid where completed days,
the current day, and locked future days are visually different.

### 5. AI Study Coach

Create an interactive AI Study Coach component that provides
personalized coding guidance when the user clicks the
Ask AI Coach button.

### 6. Responsive Design

Make the application responsive for both mobile and desktop
screens while maintaining a clean modern interface.

### 7. Debugging

Fix React routing, component rendering, navigation,
button interactions, and styling issues during development.
